Create responsive, customizable tabbed content in the WordPress block editor.

== Description ==

**Advanced Tabs Block** is a fast, lightweight **Gutenberg tabs block** that lets you organize content into clean, responsive **tabs** — directly inside the WordPress block editor. Built entirely with **native Gutenberg components**, it needs no page builder and no coding to create beautiful **tabbed content**.

Add any blocks inside your tabs — paragraphs, images, headings, buttons, columns, and more — then style everything with rich typography, color, spacing, border, and icon options. Perfect for FAQs, product details, pricing, feature comparisons, service listings, and any layout that benefits from organized, space-saving tabs.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/advanced-tabs-block` directory, or install the plugin through the WordPress Plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Open the Gutenberg block editor and find the "Advanced Tabs Block" in the block inserter.
4. Add the block, then drag and drop your content into each tab.

== Frequently Asked Questions ==

= Is the tabs block responsive? =
Yes. Advanced Tabs Block is 100% responsive and adapts to all screen sizes.

= Does it require a page builder? =
No. It is built entirely with native Gutenberg components and works directly in the WordPress block editor.

= What content can I put inside a tab? =
Any block — paragraphs, images, headings, buttons, columns, and more can be added as tab content.

= Can I add icons to the tab titles? =
Yes. You can use built-in Bootstrap Icons or add your own custom SVG icons for each tab title.

= Does it slow down my site? =
No. The block is lightweight and loads its assets only on pages where the block is actually used.
